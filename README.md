# 숏츠 자동화 스튜디오

주제 찾기, 구조 분석, 대본, 음성, 이미지, 자막 영상까지 한 화면에서 만드는 단일 HTML 프로그램입니다.
설치가 필요 없고, 사용자 본인의 API 키(OpenAI, YouTube Data API v3)를 입력해 브라우저에서 직접 호출합니다.
키는 저장하지 않습니다(옵션으로 이 브라우저에 기억하기 가능).

## 사용
1. `index.html`을 크롬이나 엣지로 엽니다(GitHub Pages로 공개하면 주소로도 열 수 있습니다).
2. 1단계에서 두 API 키를 입력하고 "키 확인"을 누릅니다.
3. 2~6단계를 차례로 진행합니다: 주제 찾기(구독자 대비 조회수) → 구조 분석 → 대본 → 음성·이미지 → 영상 렌더링.

## 참고
- 영상은 브라우저에서 실시간으로 녹화되므로 렌더링 중에는 탭을 앞에 두세요.
- 남의 영상의 문장·음성을 그대로 쓰지 말고 구조만 참고하세요. 업로드 시 유튜브의 AI 생성 콘텐츠 공개 항목을 확인하세요.
- API 사용 비용은 본인 계정에서 발생합니다.

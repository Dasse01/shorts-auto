숏츠 자동화 설치 마법사

영상의 설치 순서(프로그램 가져오기, API 키, 힉스필드 MCP, 로컬 TTS, 실행)를 한 화면에서 진행합니다. 키는 이 페이지 안에서만 쓰이며 어디에도 저장하거나 전송하지 않습니다(키 확인 시 OpenAI·Google 서버에 직접 요청).

0 / 6 단계 완료체크하거나 검증이 통과하면 완료로 표시됩니다
1

프로그램 가져오기

안티그래비티를 설치해 실행하고, 빈 폴더(예: shorts_auto)를 연 뒤 오른쪽 채팅창에 아래 문장을 붙여넣습니다. GitHub 주소는 영상 설명란에 있습니다.

(GitHub 주소를 입력하면 문장이 만들어집니다)
낯선 저장소는 에이전트가 코드를 그대로 실행합니다. 설치 전에 저장소의 README와 파일 목록을 한 번 훑어보고, 작성자가 맞는지 확인하세요.
2

API 키 확인

가지고 계신 두 키를 붙여넣고 확인합니다. 확인은 가장 작은 요청(모델 목록 조회, 영상 1건 조회)만 보냅니다.

키 확인이 막힐 때

회사·학원 네트워크나 브라우저 확장 프로그램이 요청을 막으면 "연결 실패"로 나옵니다. 이 경우 키 자체는 문제가 아닐 수 있으니 3단계로 넘어가도 됩니다. OpenAI는 결제 충전이 안 되어 있으면 키가 유효해도 이후 호출에서 오류가 납니다.

3

(2단계에서 키를 입력하면 미리보기가 나옵니다)

폴더 저장은 크롬·엣지에서 작동합니다. 프로그램 폴더를 고르면 거기에 .env를 씁니다. 이미 있으면 덮어쓰기 전에 한 번 더 확인합니다. 복사한 내용은 안티그래비티에서 .env 파일을 열어 붙여넣고 저장해도 됩니다.

4

힉스필드 MCP 연결

  1. 힉스필드 사이트에 로그인하고 상단 메뉴의 MCP를 엽니다.
  2. CLI 탭에서 "명령어를 복사해서 에이전트로 보내기"를 누릅니다. 명령어는 사이트에서 복사한 것을 그대로 써야 합니다.
  3. 안티그래비티 채팅창에 아래 문장을 쓰고, 바로 아랫줄에 복사한 명령어를 붙여넣어 보냅니다.
  4. 중간에 브라우저 창이 뜨면 힉스필드 계정으로 한 번 로그인합니다.
힉스필드 mcp 연결해줘
5

로컬 TTS (피노키오 + Qwen3-TTS)

  1. 피노키오를 설치하고 실행합니다.
  2. 왼쪽 탐색(Explore)에서 QN3를 검색해 Qwen3 TTS를 Install 합니다.
  3. 내 앱(My Apps)에서 Qwen3 TTS를 열어 모델을 설치합니다: Voice Design, Base, Custom Voice. 그래픽카드가 없거나 느린 PC는 0.6B, 사양이 좋으면 1.7B.
  4. Run을 누르고 터미널에 나오는 http://… 주소를 복사해 아래에 넣습니다.
(주소를 입력하면 문장이 만들어집니다)

위 문장을 안티그래비티 채팅창에 보내면 프로그램과 피노키오 음성 서버가 연결됩니다. 피노키오를 끄면 주소가 바뀌거나 응답이 없을 수 있으니 영상 제작 전에 Run 상태를 확인하세요.

6

실행

안티그래비티 오른쪽 위의 패널 아이콘으로 터미널을 열고 아래 명령을 입력합니다. 나온 로컬 주소를 크롬에 붙여넣어 엽니다. 컴퓨터를 껐다 켤 때마다 이 단계를 다시 합니다.

pnpm dev
